# My AZKATECH Website

A responsive 4-page business website, built as Task 1 using HTML, CSS and Flexbox.

## Pages
- index.html - Home
- about.html - About
- services.html - Services
- contact.html - Contact

## Features
- Sticky navigation bar with hover dropdown menus
- Mobile menu (hamburger button and side panel)
- Responsive layout using Flexbox and media queries
- CSS split into one file per section

## How to run
Download the project and open index.html in your browser.

## Built with
HTML, CSS and a little JavaScript
